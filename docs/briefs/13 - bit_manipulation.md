# פעולות סיביות

## מה המבחן שואל
כמעט תמיד יש בבונוס או באחד מסעיפי החלק האמריקאי פעולת סיביות אחת, ולפעמים שלוש בשורה אחת:
- `21B-A-Q4b`: מה נכנס בצד שמאל של `int` חיובי בהזזה ימינה.
- `22B-A-Q5`: `z ^ 1`, `pow` והזזת שמאלה בתוך `putchar`.
- `23B-B-Q6`: `'^' ^ '^'` בתוך אתחול מערך תווים.
- `24B-A-Q5b`: הערך של `3 ^ 2`.
- `24B-B-Q6`: הזזות מקוננות עם `long long` והמרה ל-`int`.
- `25B-A-Q5b`: `24 << 1`.

## הרעיונות המרכזיים
| פעולה | משמעות | דוגמה |
|---|---|---|
| `a & b` | AND: 1 רק כששתי הסיביות 1 | `6 & 3 = 2` (110 & 011 = 010) |
| OR (הקו האנכי הבודד) | 1 אם לפחות אחת מהסיביות 1 | 6 OR 3 = 7 (110 OR 011 = 111) |
| `a ^ b` | XOR: 1 כשהסיביות שונות | `3 ^ 2 = 1` (11 ^ 10 = 01) |
| `~a` | NOT: הופך כל סיבית | `~0 = -1` |
| `a << k` | הזזה שמאלה: כפל ב-`2^k` (נכנסים אפסים מימין) | `24 << 1 = 48` |
| `a >> k` | הזזה ימינה: חילוק שלם ב-`2^k` | `13 >> 1 = 6` |

- הזזה ימינה של מספר **חיובי** ממלאת מצד שמאל בסיביות 0 (`21B-A-Q4b`). במספר שלילי התנהגות המילוי תלויה במערכת (בדרך כלל מכפילים את סיבית הסימן).
- `x ^ x` הוא 0, ו-`x ^ 0` הוא `x`. `x ^ 1` הופך את הסיבית הימנית ביותר: זוגי הופך לבא אחריו, ואי-זוגי לקודם לו (`z ^ 1` עבור `z` אי-זוגי שווה `z - 1`).
- `-1` מיוצג כמספר שכולו 1. לכן `-1 & -1 = -1`, ו-`-1 | x = -1`, ו-`(int)(2^32 - 1)` על מערכת של 32 סיביות הוא -1.
- ערך של `x & mask` הוא אפס או שונה מאפס, ולכן אפשר להשתמש בו כתנאי.
- גודל סוגי המספרים: `int` הוא בדרך כלל 32 סיביות, `long long` 64. הזזה של `1` ב-`32` או יותר בתוך `int` אינה מוגדרת, ולכן `(long long)1 << 32` כותבים עם המרה.
- ל-`^` ול-`&` קדימות **נמוכה** מהשוואות (`==`), ולכן `x & 1 == 0` שגוי. כותבים `(x & 1) == 0`.

## תבניות C: מסכות
```c
#include <stdio.h>

int get_bit(unsigned x, int k)   { return (x >> k) & 1; }
unsigned set_bit(unsigned x, int k)    { return x | (1u << k); }
unsigned clear_bit(unsigned x, int k)  { return x & ~(1u << k); }
unsigned toggle_bit(unsigned x, int k) { return x ^ (1u << k); }

int count_ones(unsigned x)
{
    int c = 0;
    while (x)
    {
        c += x & 1;
        x >>= 1;
    }
    return c;
}

int is_power_of_two(unsigned x)
{
    return x != 0 && (x & (x - 1)) == 0;
}

void print_binary(unsigned x, int bits)
{
    int i;
    for (i = bits - 1; i >= 0; i--)
        putchar('0' + get_bit(x, i));
    putchar('\n');
}

int main()
{
    unsigned x = 0x2A;                          /* 101010 */
    print_binary(x, 8);                         /* 00101010 */
    print_binary(set_bit(x, 0), 8);             /* 00101011 */
    print_binary(clear_bit(x, 5), 8);           /* 00001010 */
    print_binary(toggle_bit(x, 1), 8);          /* 00101000 */
    printf("%d %d %d\n", count_ones(x), is_power_of_two(64), is_power_of_two(48)); /* 3 1 0 */
    return 0;
}
```

## מתכון: פלט של ביטוי עם הזזות (`24B-B-Q6`)
```c
#include <stdio.h>

int main()
{
    /* innermost first: 1<<1 = 2, 1<<2 = 4, 4+1 = 5, 1<<5 = 32, (long long)1<<32 = 2^32, minus 1, then (int) */
    printf("%d\n", (int)(((long long)1 << (1 << ((1 << (1 << 1)) + 1))) - 1));
    return 0;
}
```
1. עבדו מהסוגריים הפנימיים החוצה והעתיקו כל תוצאה: 2, 4, 5, 32.
2. `2^32 - 1` ב-`long long` הוא 32 סיביות של 1.
3. ההמרה ל-`int` חותכת ל-32 סיביות, כולן 1, שזה -1 בהשלמה ל-2. הפלט: `-1`.

## דוגמה פתורה: `23B-B-Q6`
`char s[] = {'^', '^', '^' ^ '^', '^'};` — האיבר השלישי הוא `'^' ^ '^'`, כלומר 0, שהוא `'\0'`. לכן `printf("%s", s)` מדפיס רק את שני התווים הראשונים: `^^`. התו הרביעי כבר לא נקרא.

ובדומה `22B-A-Q5`: `z = 'z' - 1` הוא `'y'` (אי-זוגי), אז `z ^ 1` הוא `z - 1`, וההפרש `(z^1) - z` הוא -1. החזקה `(-1)` ל-`z << 1` (זוגי) היא 1, ו-`z - 1` הוא `'x'`.

## מלכודות
> 🪤 `1 << 31` ב-`int` חורג ממספר חיובי (סיבית הסימן), ו-`1 << 32` אינו מוגדר. השתמשו ב-`1u` או ב-`long long`.

> 🪤 `a & b == c` מתפרש `a & (b == c)`. סוגריים תמיד.

> 🪤 `~x` על `unsigned` ו-`int` נותן ערכים שונים כשמדפיסים (`%d` מול `%u`).

> 🪤 `a << 1` כפל ב-2 רק כל עוד אין גלישה. `24 << 1` הוא 48 (לא 2.4 ולא 240).

> 🪤 `&&` ו-`||` (לוגיים) לא כמו `&` ו-`|` (סיביות): `3 && 4` הוא 1, `3 & 4` הוא 0.
