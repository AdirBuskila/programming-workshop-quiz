# מערכים סטטיים ודו-ממדיים

## מה המבחן שואל
מערך דו-ממדי סטטי מופיע כקלט לפונקציה שבונה מערכים דינמיים (`25B-A-Q2` עם `int A[][N]`), וכשאלה אמריקאית על הקשר בין אינדקס לחשבון מצביעים (`22B-B-Q4b`: מה מדפיס `*a[i]` ו-`*(*(a+i)+i)`). המיומנויות: אינדקסים של אלכסון ומשולש, סדר האחסון בזיכרון, והעברת מערך לפונקציה.

## הרעיונות המרכזיים
- מערך `int a[5]` הוא 5 תאים רציפים. ל-`a[i]` אין בדיקת גבולות: חריגה היא התנהגות לא מוגדרת.
- שם מערך בביטוי הוא כתובת התא הראשון: `a == &a[0]`, ו-`a[i] == *(a + i)`.
- מערך מועבר לפונקציה כ**כתובת**, ולכן הפונקציה משנה את המקור (by reference). `sizeof` בתוך הפונקציה נותן את גודל המצביע, לא של המערך.
- מערך דו-ממדי `int a[3][3]` נשמר שורה אחר שורה (row-major). `a[i]` היא שורה שלמה (כתובת התחלתה), ו-`a[i][j] == *(*(a + i) + j)`.
- בפרמטר של פונקציה חובה לציין את מספר העמודות: `int A[][N]` (ו-`N` קבוע שהוגדר מעל הפונקציה).
- אתחול חלקי מאפס את השאר: `int a[5] = {0};` מאפס את כל המערך. בלי אתחול, מערך מקומי מכיל זבל.
- מערך אי אפשר להשים למערך (`b = a` לא חוקי), אלא רק להעתיק איבר איבר או עם `memcpy`.

## אינדקסים שכדאי לדעת (מטריצה `n×n`)
| אזור | תנאי |
|---|---|
| אלכסון ראשי | `j == i` |
| אלכסון משני | `j == n - 1 - i` |
| משולש שמאלי תחתון (כולל אלכסון) | `j <= i`, בשורה `i` יש `i + 1` איברים |
| משולש עליון ממש | `j > i`, בשורה `i` יש `n - 1 - i` איברים |
| משולש שמאלי עליון (כולל משני) | `j <= n - 1 - i`, בשורה `i` יש `n - i` איברים |

(במשולש "שמאלי עליון" של `25B-A-Q2` הקוד הרשמי עובר על `j < n - i`.)

## תבנית C: פלט של קטע על מערך דו-ממדי
```c
#include <stdio.h>

int main()
{
    int a[3][3] = {{1, 2, 3}, {4, 5, 6}, {7, 8, 9}}, i;
    for (i = 0; i < 3; i++)
        printf("%d %d ", *a[i], *(*(a + i) + i));
    printf("\n");
    return 0;
}
```
הפלט הוא `1 1 4 5 7 9`: `*a[i]` הוא `a[i][0]` (הספרות 1, 4, 7), ו-`*(*(a+i)+i)` הוא `a[i][i]` (האלכסון 1, 5, 9) (`22B-B-Q4b`).

## מתכון לפתרון
1. כתבו את גבולות הלולאה לפי הטבלה למעלה, ולא לפי "כל המטריצה" כשהשאלה מבקשת חלק.
2. כשמעתיקים משולש למערך דינמי, אורך השורה `i` נקבע מהטבלה, והעמודה במערך החדש היא `j - offset` כשהשורות מוזזות (ראו [[dynamic_arrays_2d]]).
3. אם צריך לעבור על עמודות: לולאה חיצונית על `j`, פנימית על `i`, וגישה `ar[i][j]`.
4. לבדיקת "ממוין ממש עולה" בשורה, סימן הכישלון הוא `a[i] <= a[i-1]`. בעמודה "ממוינת ממש יורד" הכישלון הוא `ar[i][col] >= ar[i-1][col]`.

## דוגמה פתורה
חיבור האלכסון הראשי והמשני של מטריצה סטטית:
```c
#define N 4

int diagonals_sum(int A[][N], int n)
{
    int i, sum = 0;
    for (i = 0; i < n; i++)
    {
        sum += A[i][i];
        if (i != n - 1 - i)          /* odd n: the center counts once */
            sum += A[i][n - 1 - i];
    }
    return sum;
}
```

## מלכודות
> 🚧 `int A[][]` בפרמטר לא מתקמפל. רק המימד הראשון יכול להישאר ריק.

> 🚧 `sizeof(arr)/sizeof(arr[0])` בתוך פונקציה לא נותן את מספר האיברים (גודל מצביע חלקי גודל איבר). מעבירים את הגודל כפרמטר.

> 🚧 `a[3]` במערך בגודל 3 הוא כבר מחוץ לתחום. האינדקס האחרון הוא `n - 1`.

> 🚧 מערך סטטי הוא כתובת קבועה: אסור `a = b` ואסור `free(a)` (ראו [[dynamic_memory]]).
