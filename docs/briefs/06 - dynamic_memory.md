# הקצאה דינמית

## מה המבחן שואל
כל שאלת קוד בת 40 נקודות מקצה זיכרון, ובחלק האמריקאי יש שאלות על ההתנהגות המדויקת של `malloc` ו-`realloc`. דוגמאות:
- `22B-A-Q4c`: מה קורה אחרי `malloc(0)`.
- `24B-A-Q5a`: `free` על מערך סטטי.
- `24B-B-Q5b`: `realloc(NULL, size)`.
- `21B-A-Q4a`: אילו משתנים מאותחלים כברירת מחדל, ו-`malloc` מול `calloc`.

בשאלות הקוד המבחן בודק: הקצאה בגודל מדויק, סימון ריק (`NULL` ו-0), שחרור זיכרון מתי שנדרש (למשל בשאלת מטריצה שמחליפה מטריצה ישנה), ושימוש ב-`realloc` לקיצוץ.

## הרעיונות המרכזיים
- `malloc(bytes)` מקצה בלוק בבתים בלי לאפס אותו. `calloc(count, size)` מקצה ומאפס. ה-`(T*)` לפני הקריאה אינו חובה ב-C אבל נהוג להשאיר אותו בקורס.
- גודל תמיד כך: `n * sizeof(T)`, לא מספר קבוע. לשורת מטריצה `int`: `calloc(cols, sizeof(int))`. למצביעים: `sizeof(int*)`.
- הקצאה יכולה להיכשל ולהחזיר `NULL`. בשאלות אומרים "ניתן להניח שיש מקום להקצאה", ואז לא חייבים לבדוק.
- `free(p)` משחרר בלוק שהוקצה. אחריו `p` עדיין מחזיק את הכתובת הישנה (מצביע תלוי). ל-`free(NULL)` אין השפעה והוא חוקי.
- `realloc(p, newBytes)` משנה גודל בלוק: ההקצאה עשויה לעבור לכתובת חדשה, התוכן נשמר עד הגודל הקטן מבין השניים, והישן משוחרר אוטומטית. ב-`realloc(NULL, n)` הוא כמו `malloc(n)`.
- `malloc(0)` ו-`realloc(p, 0)` תלויים במימוש (יכול להחזיר `NULL` או כתובת שאסור לגשת אליה). בשאלה `22B-A-Q4c` התשובה הרשמית: `p` יצביע על איזשהו מקום.
- אסור `free` על משהו שלא הוקצה דינמית (מערך סטטי, משתנה מקומי, מחרוזת קבועה) או על אמצע בלוק. `free` פעמיים על אותו בלוק גם אסור (double free).
- דליפת זיכרון: הקצאה שאין עליה `free` ואין עוד מצביע אליה.
- משתנים מקומיים בלי אתחול מכילים זבל. משתנים גלובליים ו-`static` מתאפסים. קבועי `enum` מקבלים 0, 1, 2... אוטומטית.

## הדפוס "ספירה ואז הקצאה"
כשלא יודעים מראש כמה תוצאות יהיו (תנאי על איברי מערך, שורות בקובץ): עוברים פעם אחת וסופרים, מקצים בדיוק, ועוברים פעם שנייה ומלאים. או: מקצים את הגודל המקסימלי, ממלאים, וקוצרים עם `realloc`.

```c
/* returns a new array of the elements divisible by d; *size = their number */
int *divisible(const int *a, int n, int d, int *size)
{
    int i, k = 0, *res;
    *size = 0;
    for (i = 0; i < n; i++)             /* pass 1: count */
        if (a[i] % d == 0)
            (*size)++;
    if (*size == 0)
        return NULL;
    res = (int *)calloc(*size, sizeof(int));
    for (i = 0; i < n; i++)             /* pass 2: fill */
        if (a[i] % d == 0)
            res[k++] = a[i];
    return res;
}

/* the same with one pass and a trim */
int *divisible2(const int *a, int n, int d, int *size)
{
    int i, k = 0;
    int *res = (int *)calloc(n, sizeof(int));   /* upper bound */
    for (i = 0; i < n; i++)
        if (a[i] % d == 0)
            res[k++] = a[i];
    *size = k;
    res = (int *)realloc(res, k * sizeof(int)); /* trim to the real size */
    return res;
}
```
(`realloc` לגודל 0 עלול להחזיר `NULL` ולשחרר, בהתאם למימוש: אם השאלה דורשת `NULL` כשאין תוצאות, כתבו זאת במפורש.)

## שחרור מטריצה או מערך של רשימות
```c
void free_matrix(int **m, int rows)
{
    int i;
    for (i = 0; i < rows; i++)
        free(m[i]);          /* every row first */
    free(m);                 /* then the array of row pointers */
}
```
הסדר חשוב: אם משחררים את `m` קודם, אין יותר דרך להגיע ל-`m[i]`.

## מתכון לפתרון
1. סמנו על דף מה הגודל המדויק (איברים, שורות, `+1` למחרוזת).
2. החליטו: האם אפשר לחשב את הגודל לפני ההקצאה? אם כן, ספירה ואז הקצאה. אם לא: גודל מקסימלי ו-`realloc` בסוף.
3. בדקו מה הפונקציה מחזירה כשאין תוצאה (בדרך כלל `NULL` ו-0).
4. אם השאלה אומרת "תשחרר את המקור" (כמו `24B-B-Q2`), השתמשו ב-`free_matrix` רק אחרי שהעתקתם את כל הנתונים.
5. בקוד עזר שהקצה מערך עזר זמני (`dig_num` ב-`24B-B-Q1`) זכרו `free` לפני `return`.

## דוגמה פתורה: קיצוץ אחרי מילוי
```c
#include <stdio.h>
#include <stdlib.h>

int main()
{
    int a[6] = {4, 9, 12, 7, 18, 3}, i, k = 0;
    int *r = (int *)calloc(6, sizeof(int));      /* upper bound: all 6 */
    for (i = 0; i < 6; i++)
        if (a[i] % 3 == 0)
            r[k++] = a[i];
    r = (int *)realloc(r, k * sizeof(int));      /* trim to k = 4 */
    for (i = 0; i < k; i++)
        printf("%d ", r[i]);
    printf("(%d)\n", k);                         /* 9 12 18 3 (4) */
    free(r);
    return 0;
}
```
מקצים את הגודל המקסימלי, ממלאים, ומקצצים בסוף. הציבו את תוצאת `realloc` בחזרה ל-`r`.

## מלכודות
> 🚧 `malloc(n)` במקום `malloc(n * sizeof(int))` מקצה פי 4 פחות ממה שצריך.

> 🚧 `realloc` יכול להחזיר כתובת חדשה: חייבים להציב אותה בחזרה (`p = realloc(p, ...)`). הכתובת הישנה כבר לא תקפה.

> 🚧 `free(*p)` כש-`*p` מצביע למערך סטטי הוא שגיאת ריצה (`24B-A-Q5a`).

> 🚧 `malloc` לא מאפס; להצטברות (`+=`) או מונים צריך `calloc` או אתחול מפורש.

> 🚧 לאחר `free(p)` לא ניגשים ל-`p->next`. שמרו `next` בצד לפני השחרור.
