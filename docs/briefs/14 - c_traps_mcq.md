# מלכודות C ושאלות אמריקאיות

## מה המבחן שואל
החלק הקצר של המבחן (שאלות 4-6, כ-30 נקודות) מורכב מ"מה מודפס" עם נימוק, חמש עד עשר טענות אמריקאיות עם בחירה ונימוק (במועדי 2021-2022 אפילו 20 נקודות), ובונוס. כל אחת מהן מסתירה מלכודת אחת מרשימה קצרה וחוזרת. הדוגמאות:
- `21B-A-Q4a`: מה מאותחל כברירת מחדל.
- `23B-B-Q5a`: איזו קריאה ל-`printf` לא נותנת 0.
- `25B-A-Q5a`: `sizeof` של מצביעים.
- `25B-A-Q6`, `25B-B-Q6`, `21B-A-Q5`, `22B-B-Q5`, `23B-A-Q6`: בונוסים עם `fgetc`, חילוק תווים, `sizeof`, `strcmp`.

הציון על כל סעיף כולל את **הנימוק**: כתבו משפט או שניים עם הכלל שעליו הסתמכתם.

## אסטרטגיה לשאלה אמריקאית
1. קראו את כל האפשרויות לפני שמחליטים. הקפידו על האפשרות "אף תשובה אינה נכונה" ועל "כל הטענות נכונות" (`22B-B-Q4c`, `25B-B-Q5a`): הן נבחרות לא מעט.
2. בשאלות "איזו טענה **לא** נכונה" בדקו כל אפשרות כמו True/False, והשאירו את היחידה השגויה.
3. אם יש קטע קוד, הריצו אותו בראש עם ערכים קטנים. אל תסמכו על תחושה.
4. אם התשובה תלויה במערכת (גודל מצביע), כתבו בנימוק את ההנחה: "בהנחה של 4 בתים". מפתח המבחן הרשמי (`25B-A-Q5a`) מניח 4 בתים, ולכן 444. במהדר של 64 סיביות הפלט הוא 888.

## 12 המלכודות שחוזרות
כל אחת מהן נבדקה בהרצה.

### 1. `sizeof` של מחרוזת קבועה ושל מצביע
```c
#include <stdio.h>

int main()
{
    printf("%d\n", (int)sizeof"|0\0/00\0/0|");                      /* 11: 10 chars + the final '\0' */
    printf("%d %d %d\n", (int)sizeof(char *), (int)sizeof(double *), (int)sizeof(void *)); /* all equal: 4 or 8 */
    return 0;
}
```
`sizeof` של כל מצביע זהה, ובמחרוזת קבועה הוא כולל את `'\0'` הסופי (`21B-A-Q5`, `25B-A-Q5a`).

### 2. `fgetc` ו-`EOF` בלולאה
```c
#include <stdio.h>

int main()
{
    FILE *f = fopen("trap_abc.txt", "w");
    char ch;
    fputs("abc", f);
    fclose(f);
    f = fopen("trap_abc.txt", "r");
    while (ch = fgetc(f) != EOF)        /* parsed as ch = (fgetc(f) != EOF) */
        printf("%d", ch);
    printf("\n");                        /* 111 */
    fclose(f);
    return 0;
}
```
(`25B-A-Q6`.) `!=` חזק מ-`=`, ולכן `ch` הוא תמיד 0 או 1. הצורה הנכונה: `int c; while ((c = fgetc(f)) != EOF)`.

### 3. `feof` בתחילת הלולאה
`while (!feof(f)) { fscanf(f, "%d", &x); ... }` רץ פעם אחת יותר: `feof` נעשה אמת רק אחרי שניסינו לקרוא מעבר לסוף (`22B-A-Q4a`: קובץ בן 5 מספרים, 6 איטרציות).

### 4. `fgets` עם גודל 2
`fgets(st, 2, f)` קוראת תו אחד בלבד. ב-`24B-A-Q6` נקראים 1, 2, 3, 4, ורק המספר השני בכל זוג מודפס, והפלט `24`.

### 5. מחרוזת מול מצביע
`char *s = "hi"; s[0] = 'x';` שגיאת ריצה. `s1 == s2` משווה כתובות (בדרך כלל 0). `strcmp` משווה תוכן.

### 6. `malloc` לא מאפס, `calloc` כן
ושימו לב: `malloc(0)` לא מחזיר בהכרח `NULL`, ו-`free` על מערך סטטי הוא שגיאת ריצה (`22B-A-Q4c`, `24B-A-Q5a`). `realloc(NULL, n)` כמו `malloc(n)`.

### 7. חשבון מצביעים
מצביע + מספר, מצביע - מספר, מצביע - מצביע, והשוואה. **לא** מצביע + מצביע (`23B-A-Q5b`).

### 8. העתקת מבנה עם מצביע
`p2 = p1` מעתיקה מערכי שדות בשלמותם, ומצביעים רק ככתובת. שינוי בתוכן שהמצביע מצביע אליו נראה בשני המבנים (`23B-B-Q4`). ראו [[structs_unions]].

### 9. איחוד
כל שדות האיחוד חולקים זיכרון. הכתיבה האחרונה קובעת (`25B-A-Q4`).

### 10. `static` ו-`scope`
`static` בתוך פונקציה זוכר, גלובלי מוסתר על ידי פרמטר באותו שם (`23B-A-Q4`, `24B-B-Q4`, `25B-B-Q4`). ראו [[storage_classes]].

### 11. פעולות סיביות מול לוגיות, וקדימויות
`3 ^ 2` הוא 1, `24 << 1` הוא 48, `&` נמוך מ-`==`, ו-`'^' ^ '^'` הוא `'\0'` (`23B-B-Q6`). ראו [[bit_manipulation]].

### 12. חילוק שלם וטבלת ASCII
```c
#include <stdio.h>

int main()
{
    char s[] = {'/', '/' / '/', '/' / '/' / '/', '/'};    /* 47, 1, 0, 47 */
    int i;
    for (i = 0; s[i]; i++)                                  /* stops at the 0 */
        printf("%d", s[i] / '/');
    printf("\n");                                           /* 10 */
    printf("%d %d\n", -7 / 2, -7 % 2);                      /* -3 -1 */
    return 0;
}
```
(`25B-B-Q6`.) הלולאה נעצרת באיבר שערכו 0, ולכן `s[3]` אינו נקרא.

## דוגמה פתורה: איזו קריאה לא נותנת 0 (`23B-B-Q5a`)
- `printf("%d\n", 0)`: 0.
- `printf("%.0lf\n", 0.0)`: מדפיס `0`.
- `printf("%d\n", NULL)`: `NULL` הוא קבוע 0.
- `printf("%d\n", '0')`: קוד ASCII של התו `'0'`, כלומר 48. **לא 0.**
- `printf("%d\n", '\0')`: 0.
- `printf("%d\n", EOF + 1)`: `-1 + 1`, כלומר 0.

התשובה היא `'0'`, כי תו הספרה אפס אינו המספר אפס.
