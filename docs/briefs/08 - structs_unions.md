# מבנים ואיחודים

## מה המבחן שואל
שאלת "מה מודפס" בת 10 נקודות במועד כמעט תמיד על מבנה או איחוד, וגם שאלות אמריקאיות קצרות:
- `23B-B-Q4`: העתקת מבנה שיש בו מערך `char[]` ומצביע `char*`. מי מועתק לעומק ומי משותף?
- `25B-A-Q4`: אותן שדות פעם ב-`struct` ופעם ב-`union`, כולל העברה לפונקציה by value.
- `24B-B-Q5a`: הצהרה `struct a { int b, c; } d;` — מה כל שם?
- `25B-B-Q5a`: מה אסור: מבנה בתוך עצמו או מצביע למבנה בתוך עצמו?
- `21B-A-Q4c`: איזה מערך מועבר by value (התשובה: מערך שהוא שדה של מבנה שמועבר by value).

מבנים גם מופיעים בכל שאלת קוד: רשומות בקובץ בינארי (`apartment`, `car`, `film`), איברי רשימה (`Item`), מערך של זוגות.

## הרעיונות המרכזיים
- `struct` מקבץ שדות. ההגדרה הנוחה: `typedef struct { int x; char name[20]; } Rec;`. מבנה שמצביע על עצמו חייב שם: `typedef struct item { int data; struct item *next; } Item;`.
- גישה לשדה: `r.x` על מבנה, `p->x` על מצביע למבנה (שקול ל-`(*p).x`).
- השמה בין שני מבנים מאותו טיפוס (`p2 = p1`) מעתיקה **את כל השדות**: מספרים, מערכים שבתוך המבנה (העתק מלא), ומצביעים (העתקת **הכתובת** בלבד, כלומר שני המבנים מצביעים לאותו מקום).
- העברה לפונקציה by value מעתיקה את כל המבנה (גם מערכי השדות שבו). שינוי בעותק לא משפיע על המקור, חוץ ממה שמצביעים שבתוכו מצביעים אליו.
- העברה של `&s` מאפשרת לפונקציה לשנות את המקור.
- מבנה לא יכול להכיל את עצמו (גודל אינסופי), אבל יכול להכיל **מצביע** לעצמו. מבנה יכול להכיל מבנה אחר ומצביע למבנה אחר.
- `union` מכיל כמה שדות שחולקים **אותו זיכרון**. הגודל הוא גודל השדה הגדול, ורק הערך האחרון שנכתב תקף. כתיבה לשדה אחד משנה את כל האחרים (באותו גודל).
- `sizeof(struct)` הוא לפחות סכום השדות, ועשוי להיות גדול יותר בגלל ריפוד (padding) ליישור.
- `typedef` נותן שם חדש לטיפוס. בהצהרה `struct a {...} d;` הטיפוס הוא `struct a`, `b` ו-`c` שדות, ו-`d` **משתנה**.

## פלט של מבנה עם מערך ומצביע (`23B-B-Q4`)
```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

struct TsT
{
    int val1;
    char val2[4];
    char *val3;
};

void by_value(struct TsT s)
{
    s.val3[1] = 'Y';      /* shared target: visible outside */
    s.val2[1] = 'Y';      /* the array is a private copy */
    s.val1 = 444;         /* private copy */
}

void by_address(struct TsT *s)
{
    s->val3[1] = 'X';
    s->val2[1] = 'X';
    s->val1 = 222;
}

int main()
{
    struct TsT p1, p2;
    p1.val3 = (char *)malloc(4);
    strcpy(p1.val3, "aaa");
    p1.val1 = 20;
    strcpy(p1.val2, "bbb");

    p2 = p1;                       /* val2 copied, val3 pointer shared */
    p2.val2[0] = 'Z';
    p2.val3[0] = 'Z';
    printf("%s %s %s %s\n", p1.val2, p1.val3, p2.val2, p2.val3);

    by_value(p1);
    by_address(&p2);
    printf("%d %s %s\n", p1.val1, p1.val2, p1.val3);
    printf("%d %s %s\n", p2.val1, p2.val2, p2.val3);
    free(p1.val3);
    return 0;
}
```
הפלט: `bbb Zaa Zbb Zaa`, אחר כך `20 bbb ZXa` ו-`222 ZXb ZXa`. מערך `val2` הועתק (שינוי ב-`p2` לא נראה ב-`p1`), ואילו `val3` משותף (השינוי בשני הצדדים נראה בשניהם).

## איחוד (`25B-A-Q4`)
```c
#include <stdio.h>

typedef union
{
    int x;
    int y;
} type2;

void fun(type2 b)
{
    b.x++;
    printf("%d %d\n", b.x, b.y);
}

int main()
{
    type2 b;
    b.x = 15;
    b.y = 18;           /* overwrites x: same memory */
    fun(b);             /* the copy: x++ makes both 19 */
    printf("%d %d\n", b.x, b.y);
    return 0;
}
```
הפלט: `19 19` ואז `18 18`. השדות `x` ו-`y` הם אותו תא, ולכן הערך האחרון שנכתב גובר. העותק ב-`fun` משתנה, המקור לא.

## מתכון לפתרון "מה מודפס" עם מבנים
1. לכל שדה כתבו אם הוא **ערך** (מספר או מערך שבתוך המבנה) או **כתובת** (מצביע).
2. בהעתקה: ערכים נפרדים, כתובות משותפות.
3. בהעברה by value: אותו כלל על העותק. בהעברת כתובת: הכול משתנה במקור.
4. באיחוד: ציירו תא אחד; כל כתיבה מוחקת את הקודמת.
5. כתבו את הפלט שורה אחר שורה לפי סדר הקריאות ל-`printf`.

## מלכודות
> 🚧 `p2 = p1` על מבנה עם מצביע: העתקה רדודה. אחרי שחרור אחד משני המבנים, השני מצביע על זיכרון משוחרר.

> 🚧 `s.name = "Dana"` על שדה `char[20]` לא מתקמפל. משתמשים ב-`strcpy`.

> 🚧 `p.x` כש-`p` מצביע (צריך `p->x`), ולהפך.

> 🚧 איחוד: קריאה משדה אחר מזה שנכתב אחרון נותנת את אותם בתים בפירוש שונה. בשאלה עם שני שדות `int` הם פשוט שווים.

> 🚧 `sizeof(client.id)` הוא גודל שדה אחד. בכתיבת רשומה לקובץ בינארי משתמשים ב-`sizeof(clientData)` (ראו [[files]]).

> 🚧 `struct node { struct node inner; }` שגוי (גודל אינסופי). `struct node *next;` תקין.

## פעולות על מבנים וגודל מבנה (`19S-A-Q4a`, `19B-B-Q4b`, `19S-B-Q4a`)
- פעולות **מוגדרות** על מבנה: השמה (`y = x`, מעתיקה את כל השדות), לקיחת כתובת (`&x`), גישה לשדה (`x.a`, `p->a`), `sizeof`, העברה לפונקציה והחזרה ממנה.
- פעולה **לא מוגדרת**: השוואה `x == y` (ואין גם `+` או `<` על מבנים). משווים שדה אחר שדה.
- גודל מבנה **גדול או שווה** לסכום גדלי השדות, כי המהדר מוסיף ריפוד (padding) ליישור. ב-`struct { char c; int i; char d; }` הסכום הוא 6 והגודל 12 (נבדק עם clang).
- הבדל בין מבנה לאיחוד: במבנה לכל שדה מקום משלו וגודלו לפחות הסכום. באיחוד כל השדות חולקים את אותו מקום וגודלו כגודל השדה הגדול ביותר (לפחות).
