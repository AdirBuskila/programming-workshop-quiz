# static, const ו-scope

## מה המבחן שואל
כמעט כל מועד מכיל שאלת "מה מודפס" שבה העיקר הוא **איזה משתנה** נוגעים בו: גלובלי, פרמטר או מקומי שמסתיר גלובלי, או `static` שזוכר ערך בין קריאות. הדוגמאות:
- `23B-A-Q4`: שלוש פונקציות, `x` ו-`y` גלובליים ופרמטרים באותו שם.
- `24B-B-Q4`: פונקציה עם `static int x` שמחזירה את כתובתו, וחמש קריאות עם הצבות מורכבות.
- `25B-B-Q4`: `y` גלובלי, `y` סטטי בתוך `f4`, `y` מקומי ב-`main`, ומערך מצביעים לפונקציות.
- `21B-A-Q4d`: פונקציה שמחזירה את הכתובת של משתנה `static` — האם היא תקינה?
- `22B-B-Q4a`: איזו מהמילים אינה מילה שמורה (התשובה: `global`).
- `21B-A-Q4a`: מה מאותחל כברירת מחדל.

## הרעיונות המרכזיים
- **משתנה מקומי** (בתוך פונקציה או בלוק) נוצר בכניסה ונעלם ביציאה. בלי אתחול הוא מכיל זבל. כל קריאה מתחילה משתנה חדש.
- **פרמטר** הוא משתנה מקומי שהוא עותק של הארגומנט.
- **משתנה גלובלי** מוצהר מחוץ לכל פונקציה (ב-C אין מילה `global`). חי לאורך כל התוכנית, ומאותחל ל-0 אם לא אותחל.
- **`static` בתוך פונקציה**: נוצר פעם אחת, מאותחל פעם אחת בלבד (ל-0 אם לא נכתב אחרת), וזוכר את ערכו בין קריאות. ההיקף עדיין מקומי, אבל חיי המשתנה כחיי התוכנית. לכן אפשר להחזיר את כתובתו (בניגוד למקומי רגיל).
- **היקף והסתרה**: שם בהיקף פנימי מסתיר שם זהה בהיקף חיצוני. מחפשים תמיד את ההצהרה הקרובה ביותר, מבפנים החוצה: בלוק, פרמטרים, גלובלי.
- מילים שמורות במחלקות אחסון: `auto`, `register`, `static`, `extern` (וגם `const`, `volatile`). `global` אינה אחת מהן.
- **`const`**: ערך שאי אפשר לשנות דרך השם הזה. עם מצביעים:
  - `const int *p`: אי אפשר לשנות את `*p`, אפשר להזיז את `p`.
  - `int *const p`: אפשר לשנות את `*p`, אי אפשר להזיז את `p`.
  - `const int *const p`: אסור לשנות את שניהם.
- `enum`: קבועים שערכיהם 0, 1, 2... אוטומטית, אלא אם נקבע אחרת.
- ערכי ברירת מחדל: גלובלי ו-`static` מתאפסים. מקומי בלי אתחול הוא זבל. מערך שהוקצה ב-`malloc` הוא זבל, וב-`calloc` מאופס.

## מתכון לפתרון: טבלת משתנים
1. בנו טבלה שבה עמודה לכל משתנה **שונה** (גם אם השם זהה): `x (גלובלי)`, `y (גלובלי)`, `x (פרמטר של f1)`...
2. לכל שורת קוד, קבעו לאיזו עמודה השם שבה שייך (לפי ההיקף).
3. עדכנו את הערכים לפי הסדר, ובכל `printf` רשמו מיד את הפלט.
4. ל-`static` הוסיפו שורה "ערך שנשמר", שמתעדכנת רק בהשמה אחרי האתחול, ובקריאה הבאה לא מאותחלת מחדש.
5. בקריאה עם כתובת (`fun(&y)`, `*fun(&x)`), סמנו מי מצביע על מי.

## דוגמה פתורה: `23B-A-Q4`
```c
#include <stdio.h>
int x = 30, y = 0;

void f1(int x)
{
    printf("x=%d,y=%d\n", x, y);
    x = y = 10;
}

void f2(int y)
{
    printf("x=%d,y=%d\n", x, y);
    x = y = 15;
}

int main()
{
    y = 5;
    f1(20);
    f2(y);
    printf("x=%d,y=%d\n", x, y);
    return 0;
}
```
הפלט: `x=20,y=5`, `x=30,y=10`, `x=15,y=10`.
- ב-`main` אין הצהרות, ולכן `y = 5` משנה את הגלובלי.
- ב-`f1` `x` הוא הפרמטר (20) ו-`y` גלובלי (5). ההשמה `x = y = 10` משנה את הפרמטר ואת הגלובלי `y`.
- ב-`f2` `y` הוא הפרמטר (קיבל את `y` הגלובלי, 10) ו-`x` גלובלי (30). ההשמה `x = y = 15` משנה את הגלובלי `x` ואת הפרמטר.
- ב-`main` שוב שני הגלובליים: `x=15`, `y=10`.

## דוגמה: `static` שזוכר, ופונקציה שמחזירה את הכתובת שלו (`24B-B-Q4`)
```c
#include <stdio.h>

int *fun(int *q)
{
    static int x = 1;      /* initialized once */
    int y = 1;             /* new every call */
    x++;
    y++;
    *q = y;                /* always 2 */
    return &x;             /* legal: x lives for the whole program */
}

int main()
{
    int x, y;
    x = *fun(&y);
    printf("%d %d\n", x, y);
    x = ++(*fun(&y));
    printf("%d %d\n", x, y);
    return 0;
}
```
הפלט: `2 2` ואחריו `4 2`. אחרי הקריאה הראשונה ה-`static x` הוא 2, אחרי השנייה 3, ואז `++(*fun(&y))` מגדיל אותו ל-4 ומציב ב-`x` של `main`.

## מלכודות
> 🪤 `static int y;` בתוך פונקציה לא מתאפס בכל קריאה. האתחול (כולל אפס אוטומטי) קורה פעם אחת (`25B-B-Q4`: ה-`y` הסטטי מקדם 0, 1, 2).

> 🪤 שלושה `y` שונים באותה תוכנית (גלובלי, סטטי, מקומי של `main`). לפני כל שורה כתבו מי מהם.

> 🪤 אחרי הלולאה `for (y = 5; y <= 7; y++)` ערכו של `y` הוא 8, לא 7.

> 🪤 פונקציה שמחזירה כתובת של משתנה **מקומי רגיל** מחזירה כתובת לזיכרון שכבר לא קיים. עם `static` זה תקין (`21B-A-Q4d`).

> 🪤 `int x;` בתוך פונקציה אינו מאותחל, אבל קבועי `enum` כן קיבלו ערכים (`21B-A-Q4a`), ואיברי מערך שהוקצה ב-`malloc` אינם מאופסים.

> 🪤 המילה `global` אינה מילה שמורה ב-C (`22B-B-Q4a`). הגדרת משתנה גלובלי נעשית פשוט מחוץ לפונקציות.
