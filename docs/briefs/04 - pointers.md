# מצביעים וכתובות

## מה המבחן שואל
הנושא נבחן בעיקר בשאלות קצרות: אילו פעולות על מצביעים חוקיות (`23B-A-Q5b`), הצהרה מורכבת (`22B-A-Q4b`: מה זה `double (**q)()`), הקשר בין שם פונקציה למצביע (`23B-B-Q5b`), ומעקב אחרי קוד עם `&` ו-`*` שבו שני מצביעים מצביעים לאותו משתנה (`24B-A-Q4`, 10 נקודות). זה גם הבסיס לכל שאלות הרשימות והמערכים הדינמיים.

## הרעיונות המרכזיים
- מצביע הוא משתנה שמחזיק כתובת. `int *p = &x;` אומר: `p` מצביע ל-`x`. `*p` הוא התא ש-`p` מצביע אליו, וכתיבה ל-`*p` כותבת ל-`x`.
- חשבון מצביעים מוגדר רק כך: מצביע ועוד מספר שלם (הזזה ביחידות של גודל הטיפוס, לא בבתים), מצביע פחות מספר שלם, מצביע פחות מצביע מאותו מערך (תוצאה: מספר שלם), והשוואת מצביעים. **חיבור שני מצביעים, כפל וחילוק אינם חוקיים.**
- `p[i]` שקול ל-`*(p + i)`. `&a[i]` שקול ל-`a + i`.
- `sizeof` של כל מצביע זהה (4 או 8 בתים לפי המערכת) ואינו תלוי בטיפוס שעליו הוא מצביע.
- `NULL` הוא מצביע שאינו מצביע לשום מקום. גישה דרכו היא שגיאת ריצה.
- מצביע ל-`void` מחזיק כל כתובת, אבל אי אפשר לבצע עליו `*` בלי המרה.
- שם של פונקציה הוא כתובתה. לכן `f(k)` ו-`(*f)(k)` זהות, ולכן אפשר לשמור מצביע לפונקציה: `void (*p)() = f;`.
- העברה by reference ב-C נעשית על ידי העברת כתובת: `void inc(int *x) { (*x)++; }` נקראת `inc(&n)`.

## קריאת הצהרות מורכבות
קוראים מהשם החוצה, קודם ימינה (סוגריים או פרמטרים) ואז שמאלה:
- `double (**q)();` — `q` הוא מצביע (`*`) למצביע (`*`) לפונקציה (`()`) שמחזירה `double`. התשובה בשאלה: מצביע למצביע לפונקציה (`22B-A-Q4b`).
- `int *a[5];` — מערך של 5 מצביעים ל-`int`.
- `int (*a)[5];` — מצביע למערך של 5 `int`.
- `void (*p[3])();` — מערך של 3 מצביעים לפונקציות (`25B-B-Q4`).

## תבניות C
```c
#include <stdio.h>

void swap(int *a, int *b)
{
    int t = *a;
    *a = *b;
    *b = t;
}

int f(int n)
{
    return 2 * n;
}

int main()
{
    int x = 3, y = 7, k = 4;
    int *p = &x, *q = &y;
    int arr[4] = {10, 20, 30, 40};
    int *e = arr + 3;
    int (*fp)(int) = f;

    swap(p, q);
    printf("%d %d\n", x, y);                 /* 7 3 */
    printf("%d %d\n", *(arr + 1), (int)(e - arr)); /* 20 3 */
    printf("%d %d\n", f(k), (*f)(k));        /* 8 8 */
    printf("%d\n", fp(k));                   /* 8 */
    return 0;
}
```

## מתכון: מעקב אחרי קוד עם מצביעים (`24B-A-Q4`)
1. ציירו תיבה לכל משתנה בכל פונקציה, כולל משתנים מקומיים עם אותו שם (`x` ב-`main` ו-`x` ב-`blabla` הם תיבות שונות).
2. בקריאה `g(&x, &y)` כל פרמטר מצביע הוא חץ לתיבה של `main`. כתיבה דרך חץ משנה את `main`.
3. כשהארגומנטים הם `&x, &x` שני החצים מצביעים לאותה תיבה. כתיבה דרך האחד משפיעה על הקריאה דרך השני.
4. פרמטר שהועבר **by value** (כמו `b` ב-`swap(int *a, int b)`) הוא עותק: שינוי בו לא יוצא.
5. כתבו אחרי כל קריאה את הערכים של `main` לפני ההדפסה הבאה.

## דוגמה פתורה
```c
#include <stdio.h>

int blabla(int *p1, int *p2)
{
    int y = 300, x = 1;
    *p2 = 400;
    x = x + 300;
    return (*p1 + 200);
}

int main()
{
    int x = 500;
    printf("%d\n", blabla(&x, &x));
    return 0;
}
```
שני המצביעים מצביעים ל-`x`. `*p2 = 400` הופך את `x` ל-400, ואז `*p1 + 200` הוא 600. זו השורה האחרונה בפלט של `24B-A-Q4`.

## מלכודות
> 🚧 `p1 + p2` לא חוקי; `p1 - p2` חוקי (בתוך אותו מערך) והתוצאה היא מספר שלם (`23B-A-Q5b`).

> 🚧 `int *p; *p = 5;` כותב לכתובת אקראית. מצביע חייב להצביע לזיכרון תקף לפני שמשתמשים בו.

> 🚧 `p + 1` מקדם ב-`sizeof(*p)` בתים, לא בבית אחד.

> 🚧 פונקציה שמחזירה כתובת של משתנה מקומי מחזירה כתובת מתה (ראו [[storage_classes]] לגבי `static`).

> 🚧 `(*f)(k)` זהה ל-`f(k)`. התשובה "לא תקין" או "ערך אחר" בשאלה כזו שגויה (`23B-B-Q5b`).

## הצבת כתובת במספר שלם, וסוגי מצביעים (`19S-A-Q5`, `20B-B-Q5`, `19B-B-Q4a`)
- המרה `(long long)s` הופכת כתובת למספר שלם, ואז אפשר לחשב עליו כמו על כל מספר: $(s^2 + 2s + 1)/(s+1) = s+1$. המרה חזרה `(char *)` נותנת כתובת, ו-`puts` מדפיסה מהתו שבכתובת הזאת עד סוף המחרוזת (`s+1` נותן את המחרוזת בלי התו הראשון).
- התשובה הרשמית מניחה שאין גלישה. במהדר של 64 סיביות ריבוע של כתובת עלול לגלוש, ולכן מציינים בנימוק את ההנחה הזאת.
- מצביעים שמוגדרים בשפת C: מצביע לפונקציה, לקובץ (`FILE *`), למצביע (`int **`), ו-`void *` ("מצביע להכל"). **מצביע לסיבית אינו מוגדר**, כי לסיבית בודדת אין כתובת. הכתובת הקטנה ביותר היא של בית.
